1. 2D Geometry & Raycasting (Geometry2D)

Geometry2D Exported Object / Static Namespace

Stateless 2D geometric query utilities for fast collision tests, polygon hit-testing, and ray intersection against axis-aligned bounding boxes without allocating rigid bodies or physics entities.

Geometry2D.circlesOverlap(a, b)

AspectSpecification
Signature(a: { x: number, y: number, radius: number }, b: { x: number, y: number, radius: number }) => boolean
FormulaComputes dx = a.x - b.x, dy = a.y - b.y, and r = a.radius + b.radius, returning dx * dx + dy * dy <= r * r.
Return Valuetrue if the two circles touch or overlap (inclusive boundary), otherwise false.
Notes & Edge CasesUses squared distance to avoid Math.hypot/Math.sqrt overhead. Negative or zero radii follow the same algebraic inequality directly.

Geometry2D.pointInPolygon(pt, poly)

AspectSpecification
Signature(pt: { x: number, y: number }, poly: Array<{ x: number, y: number }>) => boolean
AlgorithmIterates edges from vertex j to vertex i (starting with j = poly.length - 1, i = 0). Checks whether the horizontal ray from pt toward +X crosses each edge using ((yi > pt.y) !== (yj > pt.y)) && (pt.x < ((xj - xi) * (pt.y - yi)) / ((yj - yi) || 1e-9) + xi), toggling inside on each crossing.
Return Valuetrue if odd number of boundary crossings (inside), false if even (outside) or if poly is empty.
Notes & Edge CasesWorks for both convex and concave simple polygons, clockwise or counter-clockwise winding. Uses 1e-9 fallback denominator to prevent NaN/Infinity on near-horizontal edges; points lying directly on an edge or vertex may return either true or false depending on floating-point rounding.

Geometry2D.raycastBox(origin, dir, maxDist, box)

AspectSpecification
Signature(origin: Vector2, dir: Vector2, maxDist: number, box: { x: number, y: number, w: number, h: number }) => { hit: true, t: number, x: number, y: number } | null
AlgorithmNormalizes dir via dir.normalize() into nDir. Computes slab entry/exit distances along X and Y using inverse components (1e9 fallback when a component is 0), finds tmin = Math.max(Math.min(t1, t2), Math.min(t3, t4)) and tmax = Math.min(Math.max(t1, t2), Math.max(t3, t4)).
Return ValueWhen hit within range, returns { hit: true, t: tmin, x: origin.x + nDir.x * tmin, y: origin.y + nDir.y * tmin }. Otherwise returns null.
Conditions Returning nullnDir.magSq() === 0 (zero-length direction), tmax < 0, tmin > tmax (ray misses box slabs), tmin > maxDist (hit beyond maximum ray distance), or tmin < 0 (box starts behind or around origin such that entry t is negative).

2. Procedural Generation (ValueNoise2D & generateDungeonGrid)

ValueNoise2D Exported Class

Deterministic 2D lattice value noise generator. Hashes integer grid coordinates with a 32-bit unsigned seed and interpolates corner values using a cubic smoothstep curve.

MemberSignature / TypeDetailed Description
constructor(seed = 1337)(seed?: number) => ValueNoise2DCoerces seed to an unsigned 32-bit integer via seed >>> 0 and stores it on this.seed.
seednumberUnsigned 32-bit integer seed controlling spatial hash output.
_hash(x, y)(x: number, y: number) => numberInternal hash combining integer x, y, and this.seed with 32-bit integer multiplication and xorshift mixing, returning a normalized float in [0, 1) (>>> 0) / 4294967295).
sample(x, y)(x: number, y: number) => numberComputes integer cell (xi, yi) = (Math.floor(x), Math.floor(y)) and fractional offsets (xf, yf) = (x - xi, y - yi). Applies smoothstep easing u = xf * xf * (3 - 2 * xf) and v = yf * yf * (3 - 2 * yf) across the four lattice corners a=(xi,yi), b=(xi+1,yi), c=(xi,yi+1), d=(xi+1,yi+1) using MathEx.lerp(MathEx.lerp(a, b, u), MathEx.lerp(c, d, u), v).
generateDungeonGrid(options?) Exported Function

Generates a rectangular tile grid containing carved rooms and connecting corridors. Wall tiles are 1 and walkable floor tiles are 0.

Parameter / OptionType & DefaultDetailed Behavior
colsnumber = 24Number of columns in the returned 2D grid (width in tiles).
rowsnumber = 18Number of rows in the returned 2D grid (height in tiles).
roomCountnumber = 6Target number of rooms to place; placement runs up to roomCount * 6 total attempts.
minSizenumber = 3Minimum room width and height in tiles.
maxSizenumber = 6Maximum room width and height in tiles (clamped internally against cols - 4 and rows - 4).
  • Initialization: Allocates a rows-by-cols array filled with 1 (walls) and an empty rooms list.
  • Room Placement & Spacing: Picks random dimensions w and h and top-left coordinates x in [1, cols - w - 2], y in [1, rows - h - 2]. Rejects candidate rooms that overlap any existing room expanded by a 1-tile margin on all sides (x < r.x + r.w + 1 && x + w + 1 > r.x && y < r.y + r.h + 1 && y + h + 1 > r.y).
  • Room Carving & Centers: Appends { x, y, w, h, cx: Math.floor(x + w / 2), cy: Math.floor(y + h / 2) } to rooms and sets grid[ry][rx] = 0 across the room interior.
  • Corridor Tunneling: For each subsequent room i from 1 to rooms.length - 1, carves a horizontal tunnel from prev.cx to curr.cx along row prev.cy, then a vertical tunnel from prev.cy to curr.cy along column curr.cx, setting traversed cells to 0.
  • Return Value: Object { grid, rooms }.

3. Motion & Interpolation (Tween & Spring1D)

Tween Exported Class

Time-based single-property interpolator that mutates target[prop] each frame using a normalized progress value passed through an easing function.

Property / Constructor FieldType & DefaultDetailed Behavior
targetobject (required)Object reference whose property prop is updated.
propstring (required)Property key on target.
fromnumberCaptured automatically at construction from target[prop].
tonumber (required)Target value reached when normalized progress hits 1.
durationnumber = 0.5Total tween duration in seconds, clamped via Math.max(0.001, duration).
easefunction = Ease.outQuadEasing curve mapping rawT in [0, 1] to eased progress.
onCompletefunction | null = nullCalled once when rawT >= 1, immediately after setting this.finished = true.
elapsednumber = 0Accumulated time in seconds since tween start.
finishedboolean = falseBecomes true upon completion; once true, update(dt) returns immediately without re-firing onComplete.
update(dt)(dt: number) => voidAdds dt to elapsed, computes rawT = MathEx.clamp(this.elapsed / this.duration, 0, 1), sets this.target[this.prop] = MathEx.lerp(this.from, this.to, this.ease(rawT)), and marks finished = true when rawT >= 1.
Spring1D Exported Class

Semi-implicit Euler 1D damped spring oscillator pulling value toward target.

Property / OptionType & DefaultDetailed Behavior
valuenumber = 0Current scalar state/position of the spring.
targetnumber = valueEquilibrium target value toward which the spring accelerates.
velnumber = 0Current velocity in units per second.
stiffnessnumber = 180Spring constant k scaling displacement (this.target - this.value).
dampingnumber = 14Damping coefficient c opposing velocity this.vel.

6. Scene & Game Tween Lifecycle Hooks

Scene.tweens & Scene.addTween(tween) Scene Additions
  • this.tweens: Initialized to [] in Scene.constructor().
  • addTween(tween): Pushes tween onto this.tweens and returns tween.
  • update(dt): Iterates this.tweens calling tw.update(dt) on each tween, then filters out completed tweens via this.tweens = this.tweens.filter((tw) => !tw.finished).
Game.switchScene(name) & Game._loop(now) Game Additions
  • switchScene(name): Resets this.currentScene.tweens = [] alongside entities and timers before invoking this.currentScene.init().
  • _loop(now): Calls this.input.update(dt, this.camera) each frame so input buffers tick down with frame delta time and world mouse coordinates stay synchronized with the camera.
